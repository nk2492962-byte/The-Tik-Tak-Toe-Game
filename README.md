# 🎮 Tic-Tac-Toe Game

A simple and fun Tic-Tac-Toe game built with plain HTML, CSS, and JavaScript — no frameworks needed!

## 🕹️ How to Play

1. The game is played on a 3×3 grid
2. Player **O** goes first, followed by Player **X**
3. Players take turns clicking on empty boxes to place their mark
4. The first player to get **3 in a row** (horizontally, vertically, or diagonally) wins!
4. If all 9 boxes are filled and no one has won, the game ends in a **Draw**

## ✨ Features

- Two-player mode (same device)
- Automatic winner detection
- Draw detection when all boxes are filled
- Disables the board when the game is over
- Clean and simple UI
